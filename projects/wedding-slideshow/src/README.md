# Mã dựng slideshow “Từ hôm nay”

[Hướng dẫn tái tạo V005](../notes/tai-tao-v005.md) đi từ bộ ảnh và 13 bài nhạc đến MP4 chiếu tiệc. [Kịch bản](../notes/kich-ban-v005.md) ghi mốc chữ và các bài.

- `v005/` chuẩn bị media, tính timeline 50 fps, dựng chữ, xuất từng chương và kiểm tra bản giao.
- `v002/` đến `v004/` giữ các vòng thử template, độ mượt và hiệu ứng chữ. `render.py` dựng bản slideshow V001.
